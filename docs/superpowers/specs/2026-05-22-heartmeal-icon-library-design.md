# HeartMeal 图标库设计规格

## 1. 背景

HeartMeal / 情侣餐桌是一款面向情侣用户的轻量级微信点餐小程序。当前产品核心流程为：

```text
进入小程序 → 浏览菜单 → 添加菜品 → 查看购物车 → 填写备注 → 确认下单 → 查看订单记录
```

图标库用于统一首页、购物车、确认下单、订单记录和二期偏好能力中的图形语言，补齐当前界面主要依赖文字、按钮和色块表达的问题。

## 2. 设计目标

- 保持“轻甜、温柔、清爽、食欲、高效”的界面气质。
- 优先服务点餐效率，不让图标抢走菜品、价格和主按钮层级。
- 为 MVP 主流程提供完整操作图标，同时预留偏好、收藏、搜索、空状态等二期入口。
- 在 Figma 中以组件库方式维护，便于后续导出 SVG 或接入 Taro 小程序资源。

## 3. 风格方向

采用 **温柔圆角线性图标**：

- 基础画布：24 × 24 px。
- 线宽：默认 1.75 px，复杂或小尺寸图标可使用 2 px。
- 端点和转角：round cap / round join。
- 图形语言：线性为主，少量粉色或暖橘用于强调。
- 视觉密度：克制、清楚、适合小程序列表和按钮。

不采用大面积面性图标，也不采用明显贴纸感图标。贴纸感可在空状态插画中单独扩展，不进入基础操作图标库。

## 4. 图标范围

V1 图标库范围采用 **MVP + 二期预留**，规划约 36 个图标。

### 4.1 导航

- `home`：首页 / 菜单页。
- `menu`：菜品菜单。
- `cart`：购物车。
- `orders`：订单记录。
- `profile`：情侣偏好。

### 4.2 点餐动作

- `plus`：添加。
- `minus`：减少。
- `delete`：删除单项。
- `clear`：清空。
- `checkout`：去结算 / 确认。
- `reorder`：再来一单。

### 4.3 菜品信息

- `dish`：通用菜品。
- `rice`：主食。
- `snack`：小吃。
- `drink`：饮品。
- `dessert`：甜品。
- `spicy`：辣度。
- `hot`：热销 / 推荐。

### 4.4 情侣偏好

- `heart`：情侣感 / 喜欢。
- `couple`：两人关系。
- `taste`：口味偏好。
- `note`：备注。
- `favorite`：收藏。
- `person-two`：用餐人数 / 两人餐桌。

### 4.5 订单状态

- `calendar`：日期。
- `clock`：时间。
- `receipt`：订单小票。
- `success`：下单成功。
- `empty`：空状态。
- `warning`：提醒 / 异常。

### 4.6 二期入口

- `search`：搜索菜品。
- `filter`：筛选。
- `setting`：偏好设置。
- `star`：推荐 / 评分。
- `image`：菜品图片。
- `coupon`：优惠入口预留。

## 5. 颜色与状态

图标组件应支持 3 种语义颜色：

| 语义 | 色值 | 用途 |
|---|---|---|
| Default | `#333333` | 默认正文图标、列表图标 |
| Pink | `#FF7F9F` | 当前态、主操作、情侣偏好强调 |
| Warm | `#FF8A3D` | 价格、热销、食欲相关强调 |

弱化、禁用、辅助说明场景使用 `#888888` 或页面现有透明度控制，不单独作为主组件颜色变体。

## 6. 尺寸规范

图标原始组件以 24 px 制作，并提供使用规范：

- 16 px：标签、辅助信息、紧凑列表。
- 20 px：普通按钮、输入项、提示条。
- 24 px：导航入口、空状态、模块标题旁图标。

Figma 组件优先维护 24 px 主组件；16 px 和 20 px 可用实例缩放或通过尺寸变体承接。

## 7. Figma 文件结构

新建 Figma Design 文件：`HeartMeal Icon Library`。

建议页面结构：

```text
Cover
Foundations
Icon Components
Usage Examples
Export Notes
```

### 7.1 Cover

展示项目名称、图标风格、适用平台和版本信息。

### 7.2 Foundations

包含网格、线宽、圆角、颜色语义、尺寸说明。

### 7.3 Icon Components

按分组展示全部图标。每个图标应命名为：

```text
Icon / <Group> / <Name>
```

示例：

```text
Icon / Navigation / Cart
Icon / Action / Plus
Icon / Couple / Taste
```

### 7.4 Usage Examples

展示图标在首页、购物车底栏、订单记录、偏好提示、空状态中的典型使用方式。

### 7.5 Export Notes

记录导出规则、命名规则和小程序接入建议。

## 8. 验收标准

- Figma 文件中存在完整页面结构。
- 图标数量覆盖本规格中的 36 个名称。
- 图标统一使用圆角线性风格，视觉重量一致。
- 图标在 16 / 20 / 24 px 下仍能清楚识别。
- 组件命名稳定，能支持后续导出和代码接入。
- 色彩使用与 `docs/HeartMeal_UI_Design.md` 中的主色、辅助色保持一致。

## 9. 暂不包含

- 不设计支付、配送、商家后台、会员体系等复杂商业图标。
- 不制作完整插画库。
- 不直接修改小程序代码中的图标接入方式。
- 不引入第三方图标包作为最终视觉风格来源。
